Information Collection and Use

Smart Format Pro accesses your active Google Doc solely to read and apply text styles, table formatting, and heading structures when triggered by the user.

Data Storage & Sharing

Smart Format Pro does not transmit, store, or sell any personal information or Google Doc contents. All formatting logic runs in memory during your active editing session.

Google API Limited Use Disclosure

Smart Format Pro's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
